          회원 등급 · 업무 관리
          
          
          1·2·3단계 이름을 바꾸면 사이트 헤더·관리자 회원 목록·업무 관리 화면에 그대로 나옵니다. ‘업무 관리 최소 등급’을 2로 두면 정회원부터 업무 보드를 볼 수 있습니다(서버 RLS가 함께 막습니다).
          
          
          
            
            
            
          
          
          
          
            
          
          
          
          
          
          
            
          
          
        
          

        
          
          
          헤더 메뉴
          
          
          ↑ ↓ 로 순서를 바꾸고, 체크를 끄면 사이트에서 숨겨집니다. 왼쪽 칸은 한국어 이름, 오른쪽 칸은 영어 이름입니다(사이트 헤더의 KO | EN 에서 바뀝니다). 연결 대상에 home·workshops·news·interview·archive·info·map·tasks 중 하나를 넣으면 사이트 안의 화면으로, 직접 만든 페이지·게시판은 page/<slug>·board/<slug> 로 연결합니다. https://…를 넣으면 새 창으로 열립니다. tasks 메뉴는 로그인한 회원에게만 보입니다.

          <head> 코드
          
          
          검색엔진 확인(Google Search Console·네이버 서치어드바이저), 폰트, 픽셀 등 <meta>·<link>·<script>·<style> 태그를 그대로 붙여 넣으세요. 사이트를 열 때 자동으로 <head>에 들어가고, 이미 같은 태그가 있으면 중복해서 넣지 않습니다.
          
          
          
          
        
          
      
          
    
          

    
    
          
      
          
        
          
          
          게시판 관리
          
          
          소개·뉴스·인터뷰·정보 글을 쓰고, 발행 여부를 정합니다. 댓글 수가 함께 보입니다.

          게시판 설정
          
            
          게시판을 추가하고 이름·설명·페이지당 글 수·댓글 정책을 바꿉니다. 추가한 게시판은 사이트 #/board/<slug> 에 나타나며, 글의 ‘분류’에서 고를 수 있습니다. 기본 4개 게시판(공방 소개·공방 뉴스·작가 인터뷰·지원·공모)은 사이트의 고정 화면이라 삭제할 수 없습니다.
          
          
          
          
          
            
            
            
          
          
        
          
        
          ‘기본 댓글 정책’은 게시판을 따로 정하지 않은 곳(공방 카드 댓글 등)에 쓰입니다.

          플러그인 · 마켓
          
          
          사이트·관리자에 기능을 더하는 브라우저 JS 플러그인을 설치하고 켜고 끕니다. 켜진 플러그인만 방문자의 브라우저에 내려갑니다.
          
        
          
        
          
          
          
        
          
      
          
      
          Supabase plugins · 공개(anon)는 켜진 플러그인만 읽습니다(RLS)
          
      
          

      
          
        
          
          
          
            
          설치된 플러그인
          
            
          토글을 끄면 사이트에서 빠집니다(방문자가 새로고침할 때). 기본은 사이트에 함께 배포되는 플러그인, 마켓은 마켓 목록에서 설치, 직접은 외부 URL로 설치한 플러그인입니다.
          
          
          
        
          
        
          
          
          
            
          상태플러그인버전출처JS 주소설치일
          
            
          
          
        
          
      
          

      
          
        
          외부 URL로 직접 설치
          
        
          보안 안내 · 주소는 https:// 또는 사이트 안 경로(/assets/…)만 됩니다(http://·javascript:·data:는 서버 DB가 거부합니다). CSP 때문에 실제 실행은 사이트 자신·jsDelivr·Supabase Storage 주소만 됩니다. GitHub raw 파일은 https://cdn.jsdelivr.net/gh/사용자/저장소@버전/plugin.js 형태로 넣어 주세요. 직접 올린 외부 플러그인은 관리자 화면에서는 실행하지 않습니다(관리자 세션 보호). 사이트 방문자 화면에서만 동작합니다.
